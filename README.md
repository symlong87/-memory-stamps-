# 莫奈印记 · 方寸之间

以实体集邮册为灵感的私人风景邮票网站。已收录原始文件夹中的全部 12 张作品，保留原始 PNG，同时使用 WebP 供页面浏览。

## 使用

直接打开 `dist/index.html` 可浏览原有藏品。完整的图片添加与保存功能需要通过本地服务器或正式网站访问。

在本目录执行 `python3 -m http.server 8765 --directory dist`，访问 http://localhost:8765。

- 集邮册：每一跨页收录四枚，可翻页，也支持左右方向键。
- 全览、分类、搜索：按作品名称、地点、分类及手记寻找藏品。
- 点击邮票查看详情；可打开完整原图、下载原始 PNG、加入心选。
- 添一枚邮票：支持 JPG、PNG、WebP，最大 15 MB；图片及手记保存在当前浏览器的 IndexedDB，心选保存在本地存储。新增藏品不跨设备同步，清理浏览器网站数据会清除新增藏品。

## 文件

- `dist/index.html`：页面结构。
- `dist/style.css`：响应式纸张与装帧视觉。
- `dist/app.js`：筛选、翻页、详情、心选、图片添加及本地持久化。
- `dist/collection.js`：12 枚原有藏品目录。
- `dist/assets/`：全部原始 PNG 和 WebP 浏览版本。
- `.openai/hosting.json`：已注册的 Sites 网站身份。

## 验证

已在浏览器核对全部 12 枚藏品、三组跨页、类别筛选、全览、关键词搜索、空状态、详情、原图放大、心选刷新保存，以及添加图片后的刷新保存。已检查 1440 px 桌面和 390 px 手机布局，无横向溢出；运行时未发现控制台错误。
