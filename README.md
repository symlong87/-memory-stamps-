# 记忆邮票 · 方寸之间

以实体集邮册为灵感的风景邮票网站，现有 15 枚固定藏品，包括新增的厦门鼓浪屿、天津之眼和青岛小麦岛。保留原始 PNG，使用 WebP 供页面浏览。

## 从 GitHub 还原原图

为避免网页上传大图失败，三张新邮票的原始 PNG 按原始字节分块保存在 `backup-originals/`，校验清单位于其中的 `manifest.json`。浏览图片已直接放在 `dist/assets/`。

首次从 GitHub 下载后，在项目目录运行 `python3 serve.py --open`，会先自动合并三张原图并校验 SHA-256，再启动邮册。也可以单独运行 `python3 restore-originals.py`。还原后会为“打开邮册.command”补上执行权限，之后可直接双击启动。已有且校验一致的原图不会重复写入。

## 在电脑上使用（推荐）

在项目文件夹双击 **打开邮册.command**，保持打开的终端窗口运行，然后访问 http://127.0.0.1:8765/ 。也可在项目目录执行 `python3 serve.py`。需要 Python 3.9 或更新版本，不需要额外依赖。

- 新增图片、描述、标签和删除记录保存在项目的 `.local-data/` 文件夹，刷新或重启服务器后仍保留，不依赖浏览器存储配额。
- 第一次访问时，兼容读取并迁移本地址中此前保存在浏览器的自定义邮票和编辑，保留浏览器副本。
- 备份个人收藏时，复制整个项目文件夹（包括隐藏的 `.local-data/`）。个人数据不会提交到 Git 或随网站发布。
- 如果提示端口被占用，先关闭旧服务器，再运行本版本的启动文件；使用旧的普通静态服务器时只能保存到浏览器。

## 添加、编辑与删除

- 点击“添加新邮票”，批量选择或拖入 JPG / PNG / WebP。每张最大 15 MB，每批最多 30 张；较大批次请分批导入。
- 可单独命名、移除待导入图片，设置分类、地点、手记和标签。完全相同的图片会提示已收录。
- 点击邮票，选择“编辑描述与标签”修改名称、分类、地点、描述和标签。
- 点击详情中的“从邮册中删除”，确认后移入“已移除”。原始图片保留；在邮册上方点击“已移除”可随时恢复。
- 集邮册支持立体翻页、左右方向键、全览、分类、标签搜索、原图放大和下载，以及心选。

## 网页版

部署为静态网站时，新增图片、编辑和移除记录保存在当前浏览器的 IndexedDB，不跨设备或网站地址同步。浏览器清理网站数据会清除这些个人记录。固定的 15 枚藏品随源码发布，不受影响。直接双击 HTML 文件时，浏览器可能限制存储；请使用网站地址或上面的本地启动文件。

存储失败时显示具体原因，保留未保存的表单。关闭占用数据库的旧标签页、恢复本地服务或腾出空间后，可再次点击保存。数据库连接失败不会永久阻止后续重试。

## 文件

- `dist/`：页面和全部固定藏品；`storage.js` 负责本地服务与浏览器存储兼容。
- `serve.py`：仅监听本机的保存服务，原子保存元数据，软删除和恢复。
- `.openai/hosting.json`：现有网站身份；发布范围保持不变。

已检查本地文件模式和纯静态浏览器模式的新增、刷新保存、删除与恢复；本地连接断开时保留输入、重连后可重试保存。三张新邮票的原图已核对一致，旧版浏览器数据已兼容保留。
