# 记忆邮票 · 方寸之间

以实体集邮册为灵感的私人风景邮票网站，完整保留原有 12 张「莫奈印记」作品及原始 PNG。

## 使用

直接打开 `dist/index.html` 可浏览原有藏品。推荐通过本地服务器或正式网站访问，使用完整的图片导入与保存功能。

```sh
python3 -m http.server 8765 --directory dist
```

随后打开 http://localhost:8765。

## 功能

- **书本浏览**：每个跨页展示四枚邮票，支持前后翻页和左右方向键。桌面采用围绕书脊翻转的双面书页动画，手机适配整页翻转；尊重系统的减少动态效果设置。
- **浏览与搜索**：集邮册与全览模式、分类、心选、名称、地点、描述和标签搜索。
- **添加新邮票**：在页头或集邮册右上角打开添加窗口。支持选择或拖入 JPG、PNG、WebP，每张最大 15 MB，每次最多 30 张。可分别命名，批量填写分类、地点、标签和手记，移除待导入图片后再保存。
- **编辑邮票**：点击任意原有或新增邮票，在详情中选择「编辑描述与标签」。可修改名称、分类、地点、描述与标签；取消时不保存。
- **标签**：用逗号、空格、顿号或分号分隔，自动去重，最多 12 个，每个最多 20 字。详情中的标签可以点击筛选。
- **原图与心选**：放大欣赏、下载原图和保存心选。

## 数据保存

新增图片与编辑记录保存在当前浏览器的 IndexedDB，心选保存在本地存储。刷新后仍会保留，原有收藏数据可从第一版迁移。不会跨设备、浏览器或网站地址自动同步；清理浏览器网站数据会清除个人导入与修改，原有 12 张作品仍保存在网站中。原始图片不会因编辑描述而改变。

GitHub 保存网站源码与自带图片，不会自动接收在浏览器里新导入的图片或个人编辑记录。

## 文件

- `dist/index.html`：页面与添加、编辑、详情窗口。
- `dist/style.css`：响应式纸页、装帧和翻页视觉。
- `dist/app.js`：批量导入、描述及标签编辑、本地持久化、筛选和翻页。
- `dist/collection.js`：12 枚原有藏品与初始标签。
- `dist/assets/`：原始 PNG、WebP 浏览图和图标。
- `.openai/hosting.json`：现有 Sites 网站身份，不含登录密钥。
